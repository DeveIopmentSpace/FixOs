# FixOs Toolbox Usage Guide

### Launch Command

```ps1
irm "https://raw.githubusercontent.com/DeveIopmentSpace/FixOs/main/Toolbox/src/Toolbox.ps1" | iex
```

## Features
- **Apps Installer**: Install software from 9 different categories
- **FixOs Preset**: Run the full FixOs optimization script

## Categories
1. Browsers 
2. File Tools 
3. Dev Tools 
4. .NET Tools 
5. Communication Apps 
6. Gaming Apps 
7. Microsoft Apps 
8. Media Apps 
9. Productivity Tools 

## Keyboard Shortcuts
- **0**: Go back/Exit
- **A**: Install all apps in current category
- **1-9**: Select category or app
- **Y/N**: Confirm actions
